Ponte Bella — Prototype

This repository contains a starter prototype for the Ponte Bella luxury beauty storefront.

Features included in this scaffold:
- Next.js App Router (App dir)
- TypeScript
- Tailwind CSS
- Framer Motion
- Hero interactive effect: CSS mask + JS + Framer Motion
- PWA manifest (placeholders)

Quick start
1. Install dependencies:
   npm install
2. Run dev server:
   npm run dev
3. Replace the placeholder images in /public:
   - public/model-natural.jpg (natural model)
   - public/model-makeup.jpg (makeup version, same crop & size)
